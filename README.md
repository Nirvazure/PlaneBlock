# PlaneBlock

PlaneBlock 是经典纸笔游戏「飞机大战」的本地双人网页版本。两名玩家使用同一设备，轮流布置飞机并攻击对方棋盘。

## 当前功能

- 10×10 棋盘，双方各布置 3 架飞机
- 支持向上、向下、向左、向右放置飞机，并预览可放置位置
- 双方布置完成后开始战斗，轮流选择对方棋盘上的目标
- 击中机身会标记命中；击中机头会击毁对应飞机
- 一方击毁对手全部 3 架飞机后获胜
- 可随时重新开始一局

对局在当前页面的内存中运行。刷新或关闭页面会清空对局，不会保存到云端或跨设备同步。

## 当前不支持

项目目前不提供账号登录、在线房间、好友、对战邀请、实时同步、个人资料、头像上传或云端战绩。排行榜、对局记录和回放也尚未实现。它们原先依赖的 CloudBase 和 WebSocket 服务已从项目中移除，因此运行本项目无需云端凭据或 `.env` 文件。

如果未来要恢复在线对战或云端数据功能，需要重新选择并设计后端服务与数据迁移方案。

## 技术栈

- Next.js 14 App Router
- React 18、TypeScript
- Tailwind CSS 4、Radix UI
- Geist 字体

## 环境要求

- Node.js
- pnpm

## 本地运行

```bash
pnpm install
pnpm dev
```

打开开发服务器输出的本地地址，然后选择“开始本地对战”。无需登录或配置环境变量。

## 检查与生产构建

```bash
pnpm lint
pnpm build
pnpm start
```

`pnpm start` 用于启动已构建的 Next.js 应用；运行前先执行 `pnpm build`。
